- [ ] 행사 측에서 `KILN_API_URL` 수령

```env

```

## GWDC 심사 증거 체크

### Challenge 부합성

- [ ] AI 에이전트 지출을 사람이 정책으로 제한하는 장면

- [ ] 사용자가 위임을 중지하는 장면

### 독창성·혁신성

- [ ] LLM은 자연어 구조화만 담당한다는 설명
- [ ] 결제 판단은 결정론적 엔진이 담당한다는 설명
- [ ] 불확실한 값을 추측하지 않고 질문으로 바꾸는 장면

### 기술적 구현

- [ ] 실제 Kiln 모델명과 토큰 사용량
- [ ] 누적 예산·예약액 계산 결과
- [ ] SHA-256 감사 체인 정상 표시
- [ ] 실제 Sepolia 거래 해시와 검증 결과

### 프로덕트 완성도

- [ ] 정책 생성 → 구매 요청 → 승인·차단 → 영수증 흐름이 끊기지 않음
- [ ] 로딩·오류·API 미설정 상태가 사용자에게 명확히 표시됨
- [ ] 발표 노트북에서 새로고침 후에도 정상 동작

### 실제 상용화 가치

- [ ] 운영 전 필요한 인증·RBAC·DB·보안 검토를 솔직히 구분
