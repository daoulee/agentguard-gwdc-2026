# AgentGuard 다음 프로젝트 인계서

## 현재 완성된 데모

- 자연어 지출 문장을 정책 초안으로 변환
- 상품 종류를 카탈로그 카테고리와 연결하고 등록 판매자만 추천
- 문장에 없는 자동 승인 한도·기한을 추측하지 않고 확인 질문으로 표시
- 확인 필요 항목을 사용자가 채우기 전에는 정책 적용 불가
- 정책 적용 후 자동 승인·승인 대기·즉시 차단 3가지 시나리오 실행
- 승인·거절과 SHA-256 해시 체인 감사 로그
- 로컬 JSON 영구 저장, 반응형 UI, 단계별 자동 이동

## GWDC 평가 기준과의 연결

| 평가 기준 | 현재 증거 |
|---|---|
| Challenge 부합성 | AI 에이전트의 지출 권한을 정책으로 제한하고 사람의 승인을 연결 |
| 독창성·혁신성 | LLM 해석과 결정론적 정책 엔진을 분리하고, 불확실성을 확인 질문으로 전환 |
| 기술적 구현 | 구조화된 정책, 카탈로그 그라운딩, 입력 검증, 폴백, 해시 체인 |
| 프로덕트 완성도 | 정책 작성부터 판정·승인·감사까지 하나의 웹 흐름으로 작동 |
| 실제 상용화 가치 | 판매자·카테고리 목록을 바꿔 기업 구매, 광고 집행, API 사용료 등에 재사용 가능 |
| 데모 피칭 전달력 | 모호한 요청 → 보정·확인 → 정책 적용 → 3가지 판정의 짧은 이야기 구성 |

## 다음 프로젝트에서 우선할 작업

1. 행사에서 제공하는 FuriosaAI/Kiln API 주소·키·모델명으로 실제 추론 연결
2. 공식 Challenge B 상세 문서의 필수 기술·제출 조건 재확인
3. 테스트넷 또는 외부 감사 저장소에 최종 해시 앵커링
4. 팀원 3명의 역할 분담과 2박 3일 구현 범위 확정
5. 3분 발표 대본, 아키텍처 한 장, 실패 상황을 포함한 데모 리허설

## 현재 한계

- API 자격 증명이 없으면 안전 규칙 변환기가 동작하며 실제 NPU 추론은 아직 증명되지 않습니다.
- 결제와 블록체인 전송은 시뮬레이션입니다.
- 로그인, 사용자별 데이터 분리, 운영용 DB와 권한 관리는 아직 없습니다.
